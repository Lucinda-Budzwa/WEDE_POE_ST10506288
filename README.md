## 1. Project Overview

BAIRGS Clothing Boutique is a multi-page clothing boutique website developed as part of the WEDE5020 Web Development Portfolio of Evidence (POE).

The website represents a modern fashion boutique offering clothing, shoes and accessories. It was developed using HTML, CSS and JavaScript to provide a user-friendly and responsive online shopping experience.

Part 3 builds on the HTML structure and CSS styling completed in Parts 1 and 2 by introducing interactive website functionality, form validation, product search, shopping cart features and improved accessibility.

The website is designed to work across desktop computers, tablets and mobile devices.

### Pages Included

- **`index.html` — Home:** Introduces the boutique, displays the welcome banner and provides links to the product categories.
- **`products.html` — Products:** Displays product cards, product images and prices, with product search and sorting functionality.
- **`about.html` — About Us:** Provides information about the boutique, its background, brand story and values.
- **`contact.html` — Contact Us:** Includes contact information, a validated contact form, an embedded map, Store Locator and Track Order demonstration features.
- **`cart.html` — Shopping Cart and Checkout:** Displays selected products, calculates the cart summary and provides a checkout details form.

## 4. Website Features and Functionality

### 4.1 Product Catalogue

- Displays clothing, shoes and accessories.
- Includes product images, names and prices.
- Allows users to search for products.
- Includes product sorting functionality.
- Provides interactive product image enlargement through a lightbox.

### 4.2 Shopping Cart

- Allows users to add products to the shopping cart.
- Displays selected cart items.
- Provides cart subtotal, delivery fee and total calculations.
- Includes a checkout form for customer details.

### 4.3 Contact Form

- Includes fields for customer name, email, subject and message.
- Uses JavaScript to validate submitted information.
- Displays a confirmation message when the form passes validation.

### 4.4 Store Locator

- Allows users to enter a location and receive a demonstration response.
- Includes an embedded Google Maps location referencing Randburg Square Mall.

### 4.5 Track Order

- Allows users to enter an order number.
- Provides a demonstration tracking response.
- Live order tracking requires a connected order management system.

### 4.6 Responsive Design

The website uses CSS Flexbox, CSS Grid and media queries to adapt to different screen sizes.

## 6. Demonstration and Functionality Limitations

Some website features are demonstrations of front-end functionality rather than fully connected online services.

- The contact form validates information and displays a confirmation message but does not send an actual email.
- The checkout form validates customer details but does not process payments or submit a real order.
- Track Order provides a demonstration response and is not connected to a live order database.
- Store Locator provides a demonstration response rather than live location-based search.

These features demonstrate the use of HTML, CSS and JavaScript in developing an interactive website.
